## 💻 Projects & Practical Work

### 🔹 ServiceDrift — Local TCP Availability & Baseline Monitor

**Python | Socket Programming | Multithreading | Binary Data**

A localhost-focused monitoring tool designed to identify changes in TCP service connectivity between observations.

**Implemented and demonstrated:**
- Concurrent TCP checks using worker threads and a shared task queue
- Configurable ports, worker counts, and CSV reports
- UTC scan timestamps
- Binary snapshot serialization and validation
- Baseline comparison with connectivity-change classifications
- Automated tests and controlled localhost demonstrations

In one local demonstration, ServiceDrift identified an `OPEN → CLOSED` transition as `BECAME_UNAVAILABLE` while correctly classifying another monitored port as unchanged.

**Scope:** Service availability and baseline monitoring, not vulnerability detection or a replacement for Nmap.
